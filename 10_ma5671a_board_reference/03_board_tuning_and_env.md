# 10.3 板级环境、存储与启动检查

启动环境保存 MA5671A 的链路模式、设备身份、光路校准和镜像选择参数。

## 环境存储布局

uboot_env 位于 SPI NOR 偏移 `0x040000`，分区长度 `0x080000`（512 KiB）。其中两个环境块各为 **64 KiB**，绝对偏移为 `0x040000` 与 `0x080000`；它们在分区内的相对偏移分别为 `0x0` 与 `0x40000`。环境块大小包含格式头。

| 环境块 | 分区内偏移 | Flash 绝对偏移 | 块大小 | 对应擦除大小 |
| --- | --- | --- | --- | --- |
| 第一副本 | `0x0` | `0x040000` | `0x10000` | `0x10000` |
| 第二副本 | `0x40000` | `0x080000` | `0x10000` | `0x10000` |

环境设备按 `uboot_env` 标签和分区大小识别。环境格式、冗余选择规则与校验由启动加载器规定，擦除大小为 `0x10000`。

## 环境项与设备职责

| 环境项 | 用途与约束 |
| --- | --- |
| sgmii_mode | 选择 UNI 的 SGMII、快速 SGMII 或 SerDes 模式 |
| asc0 | 0–3 的串口复用选择；实际方向和复用状态须另行确认 |
| tx_fault_pin | 故障引脚映射；默认输出未使能 |
| nSerial / nPassword | PLOAM 身份与认证信息，属于单设备配置 |
| nDyingGaspEnable | 掉电告警配置，仍依赖硬件检测与发送条件 |
| olt_type | OLT 管理互通配置 |
| ploam_emergency_stop_state | 紧急停止状态，影响激活和激光发送许可 |
| goi_calibrated | 光路校准状态，影响运行保护策略 |
| goi_config | 包含温度表和光路参数的单板校准归档 |
| mib_file / omci_iop_mask | 初始管理实体拓扑与互通策略 |
| gDtiaGentEnable | 可选 DTI 维护服务的启用开关 |

## UNI 模式选择

`sgmii_mode` 的取值与接口配置如下，宿主端需使用匹配的串行速率和协商方式。

| 值/别名 | 接口选择 | 配置意图 |
| --- | --- | --- |
| 1 / sgmii | SGMII | 自动速度，启用 SGMII MAC 自协商 |
| 2 / sgmii_fast | SGMII | 固定 2.5 Gbit/s，关闭自协商 |
| 3 / serdes | TBI SerDes | 1 Gbit/s，启用 SerDes 自协商 |
| 4 / serdes_noaneg | TBI SerDes | 1 Gbit/s，关闭自协商 |
| 5 / sgmii_fast_auto | TBI 自动检测 | 2.5 Gbit/s 配置并启用 SerDes 自协商 |
| 未设置/不识别 | TBI 自动检测 | 自动速度；与显式值 5 的速度配置不同 |

`sgmii_mode` 配置 UNI 的速率与协商方式，EEPROM Byte12 保存标称速率。运行状态通过链路、协商和误码计数读取。

## 校准数据保全

单板校准包含三张温度相关表、激光工作年龄和光路配置。环境中的校准归档采用压缩数据和文本封装，恢复后装入光路初始化参数；`goi_calibrated` 记录校准状态。

每块板使用各自的光路校准数据，温度表覆盖该设备的工作温区。

## 主控与 VPE1 的内存约束

MA5671A 具有 64 MiB RAM。VPE1 的 1 MiB 保留区从物理 `0x03F00000` 开始，对应 KSEG0 地址 `0x83F00000`；主控操作系统使用其余内存。

VPE1 启动参数传入物理总内存容量。程序映像和运行栈使用该保留区，镜像长度受保留区容量限制。SFP 服务使用物理 `0x1F200200` 起的 `0x7AC` 字节共享区，包含两个 `0x3D0` 字节银行和 12 字节全局尾部。

## 启动检查

1. 确认串口有完整启动输出，内存容量和保留区符合板级配置。
2. 按标签、偏移和大小识别活动镜像、根文件系统、可写存储和环境分区。
3. 确认 VPE1 已提供外部 I2C 事务响应，两个地址空间和动态诊断值可读。
4. 检查光路校准就绪、温度与功率测量合理、保护和告警状态正常。
5. 检查 UNI 链路速率、协商和误码，再检查 PLOAM 激活与 OMCI 管理通道。
6. 验证业务转发、重启后的配置保持及镜像回退。
