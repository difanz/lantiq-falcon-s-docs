# 6.8 MPS 与 DFEV0

MPS 提供处理域间的消息与共享存储接口，DFEV0 属于语音前端硬件域。Falcon 的 VPE0 与 VPE1 是同一颗 MIPS 34Kc 上的两个虚拟处理单元，不是两颗独立 CPU 核。VPE1 可承担 SFP I2C 从机响应；这项用途不要求采用语音邮箱协议。

## 地址资源

| 资源 | 物理地址 | 窗口大小 |
| --- | --- | --- |
| MPS 寄存器窗口 | `0x1D004000` | `0x1000` |
| MPS 共享邮箱区 | `0x1F200000` | `0x200`（512 B） |

邮箱区与 SBS0 共享地址空间。使用时须协调共享区的分配，避免覆盖其他处理域的控制数据。消息格式、FIFO 布局和启动握手取决于通信双方采用的协议，本节不定义这些协议。

## SYS1 时钟与电源控制

SYS1 基址为 `0x1EF00000`。

| 寄存器偏移 | 名称 | MPS / DFEV0 |
| --- | --- | --- |
| `0x00` | `CLKS` | 状态：MPS bit 25，DFEV0 bit 24 |
| `0x04 / 0x08` | `CLKEN / CLKCLR` | 时钟开启/关闭，使用同一组位 |
| `0x20 / 0x24 / 0x28 / 0x2C` | `ACTS / ACT / DEACT / RBT` | 激活状态、激活、去激活、复位触发 |
| `0xB4` | `PDCFG` | 设置域去激活时是否切断电源；不是立即关断命令 |

时钟、激活和电源策略为不同状态。仅配置 `PDCFG` 不能说明该域当前已经断电。

## NTR 与板级接口

`SYS_GPON.VCC` 包含 `NTR8KEN`（bit 8）、`NTREN`（bit 7）及 `NTRFS`（bits 2:0），用于 NTR 时钟配置。片上语音域和时钟资源并不代表 MA5671A 引出了 SLIC、PCM 或 ZSI 接口；板级连接与时钟输出须分别配置。

VPE1 的执行域与共享内存接口见 [VPE1 SFP I2C](../03_cpu_subsystems/02_vpe1_sfp_i2c.md)。
