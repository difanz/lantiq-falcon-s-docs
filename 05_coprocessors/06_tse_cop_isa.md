# 5.6 COP 16 位指令集

表搜索协处理器（COP0–COP5）执行 16 位大端微码指令。每颗 COP 的代码存储器（CRAM）容量为 256 个 16 位半字（PC 范围 `0x00`–`0xFF`）。指令高位选择指令格式与操作类型，多数格式下低 3 位 `[2:0]` 控制本条指令结束时是否立即返回以及返回的数据位宽。

| 位域 | 宽度 | 功能 |
| --- | --- | --- |
| `15:11` | 5 位 | 主格式与操作码（表命令占 `15:11`，分支与立即数传送占 `15:13`） |
| `10:3` | 8 位 | 寄存器端口、表号、位号、偏移、长度或立即数（分支指令中 `6:0` 为 7 位绝对目标 PC） |
| `2:0` | 3 位 | 融合返回控制码（条件转移与位测试转移中归入 7 位目标 PC） |

## 1. 协处理器内部寄存器

微码指令直接操作的内部寄存器与标志位如下：

| 寄存器名 | 功能说明 |
| --- | --- |
| `%index` | 当前表项索引寄存器。当 `%index` 超出表容量或等于无效 `%aux` 时触发 `INVALID_INDEX` 状态 |
| `%data1`、`%data2` | 表项数据寄存器（最大 256 位）。`%data1` 支持子字段抽取 `.16`、`.48`、`.112`、`.239` 以及单比特位寻址 `.0`–`.31` |
| `%key`、`%key_mask` | 查表键寄存器与键掩码寄存器 |
| `%next`、`%prev`、`%prev_src` | 链表后继指针、前驱指针与源前驱指针寄存器 |
| `%aux` | 链表（`LLIST`）空闲表下一项指针寄存器（对应表配置字 2 的低 16 位 `AUX` 字段） |
| `%index_ptr` | 索引指针寄存器 |
| `%res1`、`%res2` | 1 位查表与比较结果标志寄存器 |
| `%err` | 3 位错误状态码寄存器 |

## 2. 融合返回字段 (`[2:0]`)

低 3 位 `[2:0]` 在满足以下任一条件时作为融合返回后缀生效：

1. `[15:14] != 0`（立即数传送、`mov %err`、`%res1` 位运算、字段传送、`now` / `tag` / `treat` 以及全部表操作命令）。
2. `[15:14] == 0` 且 `[10:7] == 0`（裸 `return` 指令）。

当 `[15:14] == 0` 且 `[10:7] != 0` 时，指令为转移指令，`[2:0]` 属于 7 位转移目标 PC 的低 3 位。

| `[2:0]` 二进制 | 十进制 | 汇编后缀 | 裸返回半字 | 硬件行为 |
| --- | --- | --- | --- | --- |
| `000` | 0 | 无 | `0x0000` (`nop`) | 不返回，PC 顺序加 1 |
| `001` | 1 | `\|\| return` | `0x0001` | 结束微码执行并返回，不附带表项数据 |
| `010`、`011` | 2、3 | 保留 | — | 保留编码 |
| `100` | 4 | `\|\| return 32` | `0x0004` | 结束微码执行并返回 32 位结果数据 |
| `101` | 5 | `\|\| return 64` | `0x0005` | 结束微码执行并返回 64 位结果数据 |
| `110` | 6 | `\|\| return 128` | `0x0006` | 结束微码执行并返回 128 位结果数据 |
| `111` | 7 | `\|\| return 256` | `0x0007` | 结束微码执行并返回 256 位结果数据 |

## 3. 空操作与转移指令

### 3.1 空操作 (`nop`)

半字 `0x0000` 为 `nop`。

### 3.2 条件转移 (`[15:13] = 000` 且 `[10:7] != 0`)

| 位域 | 名称 | 说明 |
| --- | --- | --- |
| `15:13` | 格式码 | `000` |
| `12:11` | 保留 | `00` |
| `10:7` | `cc` | 4 位条件编码（`1`–`15`） |
| `6:0` | `target` | 7 位绝对目标 PC（范围 `0`–`127`） |

条件码 `cc`（`[10:7]`）编码表：

| `cc` (十进制) | 助记符 | 转移条件 |
| --- | --- | --- |
| 1 | `goto target` | 无条件转移 |
| 2 | `[!res1] goto target` | `%res1 == 0` |
| 3 | `[res1] goto target` | `%res1 == 1` |
| 4 | `[!err] goto target` | `%err == 0` |
| 5 | `[err] goto target` | `%err != 0` |
| 6 | `[!res1\|err] goto target` | `%res1 == 0` 或 `%err != 0`（如 `0x031f` 为 `[!res1\|err] goto 0x1f`） |
| 7 | `[res1&err] goto target` | `%res1 == 1` 且 `%err != 0` |
| 8 | `[eq8] goto target` | 8 位比较相等 |
| 9 | `[ne8] goto target` | 8 位比较不等 |
| 10 | `[lt16] goto target` | 16 位比较小于 |
| 11 | `[first] goto target` | 链表首项标志为真 |
| 12 | `[last] goto target` | 链表末项标志为真 |
| 13 | `[aged] goto target` | 表项老化标志为真 |
| 14 | `[!res2] goto target` | `%res2 == 0` |
| 15 | `[res2] goto target` | `%res2 == 1` |

### 3.3 位测试转移 (`[15:13] = 001`)

| 位域 | 名称 | 说明 |
| --- | --- | --- |
| `15:13` | 格式码 | `001` |
| `12` | `n` | 极性标志：`0` 为 `[!data1.bit]`（该位为 0 时转移），`1` 为 `[data1.bit]`（该位为 1 时转移） |
| `11:7` | `bit` | `%data1` 的位号（`0`–`31`） |
| `6:0` | `target` | 7 位绝对目标 PC（`0`–`127`） |

## 4. 立即数、错误码与 `%res1` 位运算指令

### 4.1 立即数传送 (`[15:13] = 010`)

| 位域 | 名称 | 说明 |
| --- | --- | --- |
| `15:13` | 格式码 | `010` |
| `12` | `r` | 目的寄存器选择：`0` 写 `%index`，`1` 写 `%data1` |
| `11:3` | `imm9` | 9 位立即数（`0x000`–`0x1FF`） |
| `2:0` | `ret` | 融合返回码 |

示例：`0x4000` 为 `mov %index, 0`；`0x4004` 为 `mov %index, 0 || return 32`；`0x5800` 为 `mov %data1, 0x100`。

### 4.2 错误码设置 (`[15:11] = 01100`)

| 位域 | 名称 | 说明 |
| --- | --- | --- |
| `15:11` | 格式码 | `01100`（`0x0C`） |
| `10:6` | 保留 | `00000` |
| `5:3` | `imm3` | 写入 `%err` 的 3 位错误码（`0`–`7`） |
| `2:0` | `ret` | 融合返回码 |

助记符为 `mov %err, imm3`。`imm3` 与响应头状态码低 3 位对应：`0` 为正常（`OK`），`4` 为表项已存在（`ENTRY_EXISTS`），`6` 与 `7` 为微码软错误 1 与 2（`SOFT_ERR_1`、`SOFT_ERR_2`）。示例：`0x6004` 为 `mov %err, 0 || return 32`，`0x6034` 为 `mov %err, 6 || return 32`。

### 4.3 `%res1` 位运算 (`[15:11] = 01101`)

| 位域 | 名称 | 说明 |
| --- | --- | --- |
| `15:11` | 格式码 | `01101`（`0x0D`） |
| `10:8` | `op` | 3 位位运算操作码（`0`–`7`） |
| `7:3` | `bit` | `%data1` 位号（`0`–`31`）；当 `op` 为 `0`、`1`、`2` 时不使用，置 0 |
| `2:0` | `ret` | 融合返回码 |

| `op` (`[10:8]`) | 助记符 | 硬件行为 |
| --- | --- | --- |
| 0 | `mov %res1, 0` | 清零 `%res1` |
| 1 | `mov %res1, 1` | 置位 `%res1`（半字 `0x6900`） |
| 2 | `not %res1` | `%res1` 按位取反 |
| 3 | `mov %res1, %data1.bit` | 将 `%data1` 的第 `bit` 位装入 `%res1`（如 `0x6bfc` 为 `mov %res1, %data1.31 \|\| return 32`） |
| 4 | `and %res1, %data1.bit` | `%res1 = %res1 & %data1.bit` |
| 5 | `or %res1, %data1.bit` | `%res1 = %res1 \| %data1.bit` |
| 6 | `xor %res1, %data1.bit` | `%res1 = %res1 ^ %data1.bit` |
| 7 | `xorn %res1, %data1.bit` | `%res1 = ~(%res1 ^ %data1.bit)`（如 `0x6f98` 为 `xorn %res1, %data1.19`） |

## 5. 字段传送、`or` 与 `shift` 指令 (`[15:11] = 01110`)

| 位域 | 名称 | 说明 |
| --- | --- | --- |
| `15:11` | 格式码 | `01110`（`0x0E`） |
| `10:8` | `dst` | 3 位目的端口编号（`0`–`7`） |
| `7:5` | `src` | 3 位源端口编号（`0`–`7`），6 位槽号 `slot = (dst << 3) \| src` |
| `4:3` | `sel` | 2 位字段选择或移位宽度立即数 |
| `2:0` | `ret` | 融合返回码 |

目的端口 0（`%index`）定义了全部 8 个源端口：

| 源编号 (`src`) | 源端口名 |
| --- | --- |
| 0 | `%data1.16` |
| 1 | `%data1.48` |
| 2 | `%data1.112` |
| 3 | `%data1.239` |
| 4 | `%data1` |
| 5 | `%next` |
| 6 | `%prev_src` |
| 7 | `%aux` |

全部已定义的字段传送槽位、专用运算槽位及编码如下：

| 槽号 (`[10:5]`) | `dst` | `src` | 助记符 | 固件微码中的半字编码 |
| --- | --- | --- | --- | --- |
| 0 | 0 | 0 | `mov %index, %data1.16` | `0x7000` |
| 1 | 0 | 1 | `mov %index, %data1.48` | `0x7020` |
| 2 | 0 | 2 | `mov %index, %data1.112` | `0x7040` |
| 3 | 0 | 3 | `mov %index, %data1.239` | `0x7060` |
| 4 | 0 | 4 | `mov %index, %data1` | `0x7080` |
| 5 | 0 | 5 | `mov %index, %next` | `0x70a0` |
| 6 | 0 | 6 | `mov %index, %prev_src` | `0x70c4`（带 `\|\| return 32`） |
| 7 | 0 | 7 | `mov %index, %aux` | `0x70f8`（选择位 `sel = 3`） |
| 8 | 1 | 0 | `mov %prev, %data1.16` | `0x7100` |
| 16 | 2 | 0 | `mov %data1.16, %index` | `0x7200` |
| 17 | 2 | 1 | `mov %data1.16, %index_ptr` | `0x7220` |
| 18 | 2 | 2 | `or %data1, %data2` | `0x7240`（`sel` 固定为 0） |
| 19 | 2 | 3 | `mov %data1, %data2` | `0x7260`、`0x7265`（带 `\|\| return 64`） |
| 24 | 3 | 0 | `mov %data2.16, %index` | `0x7300` |
| 26 | 3 | 2 | `mov %data2, %data1` | `0x7340` |
| 27 | 3 | 3 | `shift %data2, width` | `0x7360`（32）、`0x7368`（64）、`0x7370`（96）、`0x7378`（128），`width = (sel + 1) * 32` |
| 32 | 4 | 0 | `mov %key_mask, %data1` | `0x7400` |
| 42 | 5 | 2 | `mov %key, %data1` | `0x7540` |
| 48 | 6 | 0 | `mov %res2, %res1` | `0x7600` |
| 56 | 7 | 0 | `mov %aux, %data1.16`（推测） | `0x7718`（目的 7、源 0、选择位 `sel = 3`，与槽 7 的 `0x70f8` 目的/源对称） |

## 6. `tag`、`treat` 与 `now` 指令 (`[15:11] = 01111`)

当 `[15:11] = 01111` 且 `[10:6] = 00000` 时，`[5:3]` 采用独热码选择 3 条专用指令，`[2:0]` 为融合返回码：

| `[5:3]` | 基准半字 | 助记符 |
| --- | --- | --- |
| `001` | `0x7808` | `tag` |
| `010` | `0x7810` | `treat` |
| `100` | `0x7820` | `now` |

## 7. 硬件表操作命令 (`[15] = 1`)

| 位域 | 名称 | 说明 |
| --- | --- | --- |
| `15` | 格式码 | `1` |
| `14:11` | `cmd` | 4 位表命令号 |
| `10:7` | `ext` | 扩展参数字段（偏移 `off`、长度 `len`、计数方向 `cv`、覆盖标志 `ov` 或位清除掩码） |
| `6:3` | `imm4` | 4 位表号或立即数参数（`0`–`15`） |
| `2:0` | `ret` | 融合返回码 |

表命令号 `cmd`（`[14:11]`）定义如下：

| `cmd` | 助记符格式 | `[10:7]` 扩展字段定义 |
| --- | --- | --- |
| 0 | `read imm, off, len` | `[10:9]` 偏移（`0`=0，`1`=64，`2`=128，`3`=192 位）；`[8:7]` 长度（`0`=32，`1`=64，`2`=128，`3`=256 位） |
| 1 | `clear imm, 1<<n` | `[10:7]` 位移量 `n`（掩码 `1 << n`） |
| 2 | `write imm, off, len` | 与 `read` 相同 |
| 3 | `count imm, cv` | `[8:7]` 计数步进：`0`→`0`，`1`→`0`，`2`→`+1`，`3`→`-1` |
| 4 | `searchr imm, off, len` | 与 `read` 相同（查找并在命中时读取表项数据） |
| 8 | `search imm` | 无扩展字段（查找表项，仅更新状态标志与索引） |
| 9 | `remove imm` | 无扩展字段（移除表项） |
| 10 | `add imm, ov` | `[9]` 覆盖标志 `ov`（`0` 或 `1`）；`[10]` 为附加高位标志（如 `0xd008` 与 `0xd408`、`0xd010` 与 `0xd410`） |
| 11 | `searchw imm, off, len` | 与 `read` 相同（查找并在命中时写入表项数据） |
| 12 | `settab imm` | 无扩展字段（选择活动表 `imm`） |

## 8. `IF_ACL_SEARCH_*` 8 指令尾声序列

`tse0.bin`（`IF_ACL_SEARCH_3`，PC 32）、`tse2.bin`（`IF_ACL_SEARCH_1`，PC 16）、`tse3.bin`（`IF_ACL_SEARCH_2`，PC 10）与 `tse5.bin`（`IF_ACL_SEARCH_0`，PC 10）共用同一段 8 条指令的 ACL 查找序列。该序列访问的是一对共享同一基址的 256 位普通 `LIST` 表（`tse0`/`tse2`/`tse3` 为表 4，`tse5` 为表 5）与 256 位 `TERNARY LIST` 表（`tse0`/`tse2`/`tse3` 为表 5，`tse5` 为表 6）：

| PC 偏移 | 半字 | 助记符 | `tse0` / `tse2` / `tse3` | `tse5` |
| --- | --- | --- | --- | --- |
| `+0` | `0x7340` | `mov %data2, %data1` | 保存输入键数据至 `%data2` | 同左 |
| `+1` | `0x7718` | `mov %aux, %data1.16` | 推测为暂存索引；源字段与选择位 3 的精确语义未定 | 同左 |
| `+2` | `0x4000` | `mov %index, 0` | 置 `%index = 0` | 同左 |
| `+3` | `0x81a0` / `0x81a8` | `read 4/5, 0, 256` | `read 4, 0, 256`（表 4） | `read 5, 0, 256`（表 5） |
| `+4` | `0x7260` | `mov %data1, %data2` | 将 `%data2` 恢复至 `%data1` | 同左 |
| `+5` | `0x70f8` | `mov %index, %aux` | 从 `%aux` 恢复起始 `%index`（选择位 3） | 同左 |
| `+6` | `0xa128` / `0xa130` | `searchr 5/6, 0, 128` | `searchr 5, 0, 128`（三态表 5） | `searchr 6, 0, 128`（三态表 6） |
| `+7` | `0x70c4` | `mov %index, %prev_src \|\| return 32` | 将 `%prev_src` 装入 `%index` 并返回 32 位结果 | 同左 |

`0x7718` 在原调试打印器中对应空操作数字符串；上表根据槽位关系给出的助记符是分析假设，不是已确认 ISA。尤其 `.16/.48/.112/.239` 的选择规则与 `sel=3` 尚未完成闭合验证。`0x70f8` 的名字虽能打印，也不能据此证明对称写入的具体切片宽度。

## 本地依据与适用范围

原始六份 `tse*.bin`、`bsp/modules/onu/drv_onu_ll_cop.c` 的调试反汇编器与 `docs/COP_ISA.md`。打印器未覆盖的编码保持推测；不由助记符推导时序。

上述 `bsp/` 路径按本次审计的 `linux-3.10.49` 基线读取，属于源码/静态固件证据；不将 `linux-7.3` 移植结果或未上板验证的解释当作原固件运行事实。
