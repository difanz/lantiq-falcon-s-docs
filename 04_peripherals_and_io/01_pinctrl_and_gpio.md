# 4.1 引脚复用 (PADCTRL) 与 GPIO 控制器

Lantiq Falcon（PEB/PEF 98035）将片上最多 160 个多功能数字 I/O 引脚划分为 5 个 32 位端口组（**Port 0**–**Port 4**）。每个端口组由两个物理分离但按位一一对应的硬件模块共同管辖：
1. **引脚复用与焊盘电气控制器（`PADCTRL0`–`PADCTRL4`）**：控制每个物理焊盘的多路复用功能选择（`MUX0`–`MUX3`）、上下拉电阻、压摆率、驱动电流、开漏输出属性及封装可用性查询。
2. **通用输入输出与外部中断控制器（`GPIO0`–`GPIO4`）**：当某引脚在 `PADCTRL` 中选通为 GPIO 功能（`MUX1`）时，控制该引脚的输入输出方向、输出电平以及双边沿/高低电平外部中断触发逻辑。

---

## 1.1 五组端口的总线归属、时钟门控与中断分布

5 个端口组分布在 `SBS2`（以太网高速域）和 `FPI`（外设互连域）两条总线上，分别受控于 `SYS_ETH`（`0x1DB00000`）与 `SYS1`（`0x1EF00000`）：

| 端口组 | 全局引脚编号 | `PADCTRL` 物理基址 | `GPIO` 物理基址 | 所属总线与时钟控制域 | `PADCTRL` 时钟/复位位 | `GPIO` 时钟/复位位 | 汇总中断号 (ICU `IM1`) |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **Port 0** | `0`–`31` | `0x1DB01000` | `0x1D810000` | `SBS2` / `SYS_ETH` (`0x1DB00000`) | 位 `[20]` (`0x00100000`) | 位 `[16]` (`0x00010000`) | `IRQ 44` (`IM1 IRL4`) |
| **Port 1** | `32`–`63` | `0x1E800400` | `0x1E800100` | `FPI` / `SYS1` (`0x1EF00000`) | 位 `[20]` (`0x00100000`) | 位 `[16]` (`0x00010000`) | `IRQ 45` (`IM1 IRL5`) |
| **Port 2** | `64`–`95` | `0x1DB02000` | `0x1D810100` | `SBS2` / `SYS_ETH` (`0x1DB00000`) | 位 `[21]` (`0x00200000`) | 位 `[17]` (`0x00020000`) | `IRQ 46` (`IM1 IRL6`) |
| **Port 3** | `96`–`127` | `0x1E800500` | `0x1E800200` | `FPI` / `SYS1` (`0x1EF00000`) | 位 `[21]` (`0x00200000`) | 位 `[17]` (`0x00020000`) | `IRQ 47` (`IM1 IRL7`) |
| **Port 4** | `128`–`159` | `0x1E800600` | `0x1E800300` | `FPI` / `SYS1` (`0x1EF00000`) | 位 `[22]` (`0x00400000`) | 位 `[18]` (`0x00040000`) | `IRQ 48` (`IM1 IRL8`) |

对任一端口组进行引脚配置或读写 GPIO 电平前，必须先在其所属的 `SYS_ETH` 或 `SYS1` 控制块中置位 `PADCTRLn`（位 `20..22`）和 `Pn`（位 `16..18`）的 `CLKEN`（`+0x04`）与 `ACT`（`+0x24`）寄存器位。

## 1.2 `PADCTRL0`–`PADCTRL4` 寄存器映射与电气属性控制

每个 `PADCTRLn` 模块占用 `0x100`（256）字节地址空间。组内前 `0x80` 字节为 32 个独立的单引脚复用选择寄存器（每个引脚独占一个 32 位寄存器），后 `0x20` 字节为按位组织的 32 位电气属性寄存器（位 `p` 对应组内第 `p` 号引脚，`p = 0..31`）：

| 组内偏移 | 寄存器名称 | 读写属性 | 位域定义与硬件行为说明 |
| :--- | :--- | :--- | :--- |
| `+0x00`–`+0x7C` | `PADCTRL_MUX(p)` (`4 * p`) | RW | **引脚 `p` 复用功能选择寄存器**：位 `[1:0]` 选择 4 路复用功能之一：<br>• `00` (`0`)：`MUX0`（默认主外设功能）<br>• `01` (`1`)：`MUX1`（固定为通用数字 I/O 功能 `GPIOn.p`）<br>• `10` (`2`)：`MUX2`（第二备选外设功能）<br>• `11` (`3`)：`MUX3`（第三备选外设功能） |
| `+0x80` | `PADCTRL_PUEN` | RW | **内部上拉电阻使能位图**：位 `p = 1` 时开启引脚 `p` 的片内弱上拉电阻；`0` = 关闭上拉。 |
| `+0x84` | `PADCTRL_PDEN` | RW | **内部下拉电阻使能位图**：位 `p = 1` 时开启引脚 `p` 的片内弱下拉电阻；`0` = 关闭下拉。 |
| `+0x88` | `PADCTRL_SRC` | RW | **压摆率控制（Slew Rate Control）位图**：位 `p = 1` 时启用慢速边沿压摆率（降低高频 EMI 辐射）；`0` = 快速边沿。 |
| `+0x8C` | `PADCTRL_DCC` | RW | **驱动电流强度控制（Drive Current Control）**：每 2 位控制一个引脚的输出缓冲驱动电流档位（`00` = 2 mA，`01` = 4 mA，`10` = 8 mA，`11` = 12 mA）。 |
| `+0x98` | `PADCTRL_OD` | RW | **开漏输出（Open-Drain）控制位图**：位 `p = 1` 时将引脚 `p` 的输出级设为开漏模式（高电平时呈高阻态）；`0` = 标准 CMOS 推挽输出。 |
| `+0x9C` | `PADCTRL_AVAIL` | RO | **物理焊盘封装可用性位图（Available Pads）**：只读硬件掩码，位 `p = 1` 表示第 `p` 号引脚在当前芯片封装（如 Falcon-D / V / M / S）中实际引出并可用；位 `p = 0` 表示该引脚在当前封装中未引出，硬件忽略对其 `PADCTRL_MUX(p)` 的写操作。 |

## 1.3 全芯片引脚复用矩阵（`MUX0`–`MUX3`）

在全部 5 个端口组中，**`MUX1`（值 `1`）恒定分配给 `GPIO` 功能**，其余复用档位（`MUX0`、`MUX2`、`MUX3`）映射片上各外设信号线：

### 1. Port 0（引脚 `0`–`31`，`PADCTRL0` `0x1DB01000`）与 Port 1（引脚 `32`–`63`，`PADCTRL1` `0x1E800400`）

| 全局引脚 | 组内引脚 | `MUX0` (`0`) | `MUX1` (`1`) | `MUX2` (`2`) | `MUX3` (`3`) |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `0`–`1` | `P0.0`–`P0.1` | `RST` / `NTR` (8kHz 时钟) | `GPIO0`–`GPIO1` | — / `ntr_out` | — |
| `2`–`3` | `P0.2`–`P0.3` | `MDIO` (`MDC` / `MDIO`) | `GPIO2`–`GPIO3` | — | — |
| `4`–`8` | `P0.4`–`P0.8` | `LED` (`LED0`–`LED4`) | `GPIO4`–`GPIO8` | `GPHY` LED 信号 | `EBU` 扩展片选 |
| `9`–`14` | `P0.9`–`P0.14` | `GPHY` / `LED` 控制信号 | `GPIO9`–`GPIO14` | `ASC1` (`P0.9`–`P0.12`) | — |
| `32`–`33` | `P1.0`–`P1.1` | `ASC0` (`RXD` / `TXD`) | `GPIO32`–`GPIO33` | — | — |
| `34`–`35` | `P1.2`–`P1.3` | `I2C` (`SDA` / `SCL`) | `GPIO34`–`GPIO35` | — | — |
| `36`–`39` | `P1.4`–`P1.7` | `SSC0` (`MTSR`/`MRST`/`SCLK`/`CS0`) | `GPIO36`–`GPIO39` | `GPTC` 捕获/输出 | — |
| `40`–`43` | `P1.8`–`P1.11` | `SSC0` (`CS1`–`CS3`) / `JTAG` | `GPIO40`–`GPIO43` | `PCM` / `SYS1` NMI | — |

### 2. Port 2（引脚 `64`–`95`，`PADCTRL2` `0x1DB02000`）

Port 2 专用于外部并行以太网接口（`xMII0` / `xMII1`，支持 MII / RMII / RGMII 模式）：
* `P2.0`–`P2.15`（全局引脚 `64`–`79`）：`MUX0` 映射 `xMII0` 的 `TXCLK`、`TXEN`、`TXER`、`TXD[3:0]`、`RXCLK`、`RXDV`、`RXER`、`RXD[3:0]`、`COL`、`CRS`；`MUX1` 映射 `GPIO64`–`GPIO79`。
* `P2.16`–`P2.29`（全局引脚 `80`–`93`）：`MUX0` 映射 `xMII1` 的收发数据与时钟控制线；`MUX1` 映射 `GPIO80`–`GPIO93`。

### 3. Port 3（引脚 `96`–`127`，`PADCTRL3` `0x1E800500`）与 Port 4（引脚 `128`–`159`，`PADCTRL4` `0x1E800600`）

| 全局引脚 | 组内引脚 | `MUX0` (`0`) | `MUX1` (`1`) | `MUX2` (`2`) | `MUX3` (`3`) |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `96`–`101` | `P3.0`–`P3.5` | `EBU` 串行闪存 (`SFLASH`: `CS0`/`CS1`/`CLK`/`DI`/`DO`/`WP`/`HOLD`) | `GPIO96`–`GPIO101` | `EBU` 并行总线 (`NAND`/`LBUS`) | — |
| `102`–`113` | `P3.6`–`P3.17` | `BOOT_SEL` 启动配置锁存 / `EBU` 地址数据线 | `GPIO102`–`GPIO113` | `PCM` / `ASC1` | `GPTC` 定时器 I/O |
| `128`–`135` | `P4.0`–`P4.7` | `OPTIC` 光模块控制 (`TX_DISABLE` / `TX_FAULT` / `LOS` / `MOD_DEF` / `RSSI` 触发) | `GPIO128`–`GPIO135` | `TOD` (`1PPS` / 时间戳输出) | `DGASP` 外部告警输入 |

## 1.4 `GPIO0`–`GPIO4` 寄存器架构与边沿/电平中断控制

每个 `GPIOn`（`n = 0..4`）模块管理所属端口组的 32 根 GPIO 引脚（位 `p` 对应组内第 `p` 号引脚，`p = 0..31`）。硬件设计采用分离的「直接读写寄存器」与「无锁写 1 置位（W1S）/ 写 1 清零（W1C）寄存器」，使不同处理单元（如 `VPE0` 与 `VPE1`）修改同一端口组内不同引脚时无需软件加锁：

### 1. 数据与方向控制寄存器组（偏移 `+0x00`–`+0x24`）

| 组内偏移 | 寄存器名称 | 读写属性 | 硬件行为说明 |
| :--- | :--- | :--- | :--- |
| `+0x00` | `GPIO_OUT` | RW | **输出数据寄存器**：位 `p` 控制引脚 `p` 在输出模式下的驱动电平（`0` = 低电平，`1` = 高电平）。 |
| `+0x04` | `GPIO_IN` | RO | **输入电平采样寄存器**：实时反映引脚 `p` 焊盘上的物理逻辑电平（无论方向设为输入还是输出均可采样）。 |
| `+0x08` | `GPIO_DIR` | RW | **方向控制寄存器**：位 `p = 0` 将引脚 `p` 设为输入（高阻态）；位 `p = 1` 将引脚 `p` 设为输出（开启输出缓冲驱动）。 |
| `+0x18` | `GPIO_OUTSET` | WO (W1S) | **原子输出置高寄存器**：向位 `p` 写 `1` 将 `GPIO_OUT` 的位 `p` 置 `1`（输出高电平），写 `0` 的位保持原状。 |
| `+0x1C` | `GPIO_OUTCLR` | WO (W1C) | **原子输出拉低寄存器**：向位 `p` 写 `1` 将 `GPIO_OUT` 的位 `p` 清 `0`（输出低电平），写 `0` 的位保持原状。 |
| `+0x20` | `GPIO_DIRSET` | WO (W1S) | **原子方向置输出寄存器**：向位 `p` 写 `1` 将 `GPIO_DIR` 的位 `p` 置 `1`（切换为输出模式），写 `0` 无影响。 |
| `+0x24` | `GPIO_DIRCLR` | WO (W1C) | **原子方向置输入寄存器**：向位 `p` 写 `1` 将 `GPIO_DIR` 的位 `p` 清 `0`（切换为输入模式），写 `0` 无影响。 |

### 2. 外部中断触发极性与级联控制寄存器组（偏移 `+0x40`–`+0x5C`）

每个 `GPIOn` 模块支持对全部 32 根引脚独立配置边沿或电平中断检测，并将本组内所有已使能引脚的中断请求相或（OR）后，通过一条组级中断线（`IRQ 44`–`IRQ 48`）送入 BIU `ICU` 的 `IM1` 组：

| 组内偏移 | 寄存器名称 | 读写属性 | 硬件行为说明 |
| :--- | :--- | :--- | :--- |
| `+0x40` | `GPIO_EXINTCR0` | RW | **外部中断触发类型寄存器 0**：位 `p = 0` 选择**边沿触发（Edge）**；位 `p = 1` 选择**电平触发（Level）**。 |
| `+0x44` | `GPIO_EXINTCR1` | RW | **外部中断触发极性寄存器 1**：与 `EXINTCR0` 组合决定引脚 `p` 的触发条件（见下表）。 |
| `+0x48` | `GPIO_IRNCR` | R / W1C | **引脚中断锁存状态寄存器**：读取时位 `p = 1` 表示引脚 `p` 已触发中断；向位 `p` 写 `1` 清除该引脚的中断挂起标志。 |
| `+0x4C` | `GPIO_IRNICR` | RO | **引脚中断原始捕获寄存器**：反映未经 `IRNEN` 屏蔽的实时中断触发状态。 |
| `+0x50` | `GPIO_IRNEN` | RW | **引脚中断使能掩码寄存器**：位 `p = 1` 允许引脚 `p` 触发组级中断；位 `p = 0` 屏蔽该引脚中断。 |
| `+0x54` | `GPIO_IRNCFG` | RW | **双边沿触发模式寄存器**：当 `EXINTCR0` 位 `p = 0`（边沿模式）时，将 `IRNCFG` 位 `p` 置 `1` 使引脚在**上升沿与下降沿（Both Edges）**均触发中断。 |
| `+0x58` | `GPIO_IRNRNSET` | WO (W1S) | **原子中断使能置位寄存器**：向位 `p` 写 `1` 原子开启该引脚中断（将 `GPIO_IRNEN` 位 `p` 置 `1`）。 |
| `+0x5C` | `GPIO_IRNENCLR` | WO (W1C) | **原子中断使能清除寄存器**：向位 `p` 写 `1` 原子屏蔽该引脚中断（将 `GPIO_IRNEN` 位 `p` 清 `0`）。 |

#### 引脚外部中断触发条件真值表（按位 `p` 独立配置）

| `GPIO_IRNCFG[p]` (`+0x54`) | `GPIO_EXINTCR0[p]` (`+0x40`) | `GPIO_EXINTCR1[p]` (`+0x44`) | 引脚 `p` 硬件中断触发条件 |
| :---: | :---: | :---: | :--- |
| `0` | `0` | `0` | **上升沿触发（Rising Edge）** |
| `0` | `0` | `1` | **下降沿触发（Falling Edge）** |
| `1` | `0` | `X` | **双边沿触发（Both Rising and Falling Edges）** |
| `0` | `1` | `0` | **高电平触发（High Level）** |
| `0` | `1` | `1` | **低电平触发（Low Level）** |
