# 4.2 串行通信总线：ASC UART、I2C 与 SSC SPI

Lantiq Falcon（PEB/PEF 98035）在 100 MHz `FPI` 外设总线上集成了三类通用低速串行通信控制器：
1. **双路异步串行控制器（`ASC0` `0x1E100C00` 与 `ASC1` `0x1E100B00`）**：支持全双工 UART 通信、16 字节接收/发送硬件 FIFO、小数波特率发生器与硬件自动波特率检测。
2. **主/从双模 I2C 控制器（`I2C` `0x1E200000`）**：支持标准模式（100 kHz）、快速模式（400 kHz）与高速模式（3.4 MHz），内置 8 字深（32 字节）硬件 FIFO 与双从机地址硬件匹配引擎。
3. **同步串行 SPI 控制器（`SSC0` `0x1E100D00`）**：支持全双工 SPI 主/从模式、2–32 位可变帧位宽、硬件 FIFO 以及最多 8 路硬件片选（`CS0`–`CS7`）。

三个模块的时钟与硬件复位均受控于 `SYS1`（物理基址 `0x1EF00000`）：`ASC1` 对应位 `[11]`（`0x00000800`），`ASC0` 对应位 `[12]`（`0x00001000`），`SSC0` 对应位 `[13]`（`0x00002000`），`I2C` 对应位 `[14]`（`0x00004000`）。

## 2.1 异步串行控制器（`ASC0` `0x1E100C00` / `ASC1` `0x1E100B00`）

`ASC0` 与 `ASC1` 寄存器结构完全一致，各自占用 `0x100` 字节地址空间。`ASC0` 的发送、接收与错误中断连接至 `ICU` `IM3` 组的 `IRQ 104`（`IRL0`）、`IRQ 105`（`IRL1`）与 `IRQ 106`（`IRL2`）；`ASC1` 连接至 `IM3` 组的 `IRQ 112`（`IRL8`）、`IRQ 113`（`IRL9`）与 `IRQ 114`（`IRL10`）。

| 偏移量 | 寄存器名称 | 读写属性 | 关键位域与硬件功能说明 |

| `+0xF8` | `ASC_IRNCR` | R / W1C | **模块中断捕获状态寄存器**：位定义同 `ASC_IRNEN`，向对应位写 `1` 清除中断标志。 |
| `+0xFC` | `ASC_IRNICR` | R / W1S | **模块中断原始状态与软件强制触发寄存器**。 |

### 2. 波特率合成公式与轮询发送硬件序列

* **波特率计算公式**：当 `ASC_CLC.RMC = 1`（`f_ASC = f_FPI = 100 MHz`）、`ASC_MCON.FDE = 1`（开启小数分频）且 `ASC_MCON.BRS = 0` 时，输出波特率由 `ASC_FDV`（`0`–`511`）与 `ASC_BG`（`0`–`8191`）共同决定：
  * `Baudrate = (f_ASC * FDV_effective) / (16 * 512 * (BG + 1))`；`FDV` 编码 `0` 表示有效分子 `512`，其余编码对应 `1..511`。
  * 修改波特率时，硬件要求先向 `ASC_MCON` 清除位 `[15]` `R`（暂停波特率发生器），写入新的 `ASC_FDV` 与 `ASC_BG` 后，再将 `ASC_MCON.R` 置 `1`。
* **无中断轮询发送单字节时序**：
  1. 读取 `ASC_FSTAT`（`+0x48`），检查 `TXFFL` 字段（`(ASC_FSTAT & 0x3F00) >> 8`）是否为 `0`（等待发送 FIFO 排空）或检查 `TXFREE` 字段（`(ASC_FSTAT & 0x3F000000) >> 24`）大于 `0`。
  2. 将待发送字节写入 `ASC_TBUF`（32 位字写入 `+0x20` 或大端序 8 位字节写入 `+0x23`）。

## 2.2 主/从双模 I2C 控制器（`0x1E200000`–`0x1E20FFFF`）

Falcon 片上 I2C 控制器挂载于 `FPI` 总线物理基址 `0x1E200000`（窗口大小 64 KiB），支持主机模式（Master）与从机模式（Slave），内置一个 8 字 × 32 位（共 32 字节）的数据 FIFO，并向 `ICU` `IM0` 组输出 4 条独立中断线：
* `IRQ 18`（`IM0 IRL10`）：`I2C_LB`（Last Burst Request，最后一次突发传输请求）。
* `IRQ 19`（`IM0 IRL11`）：`I2C_B`（Burst Request，突发传输请求）。
* `IRQ 20`（`IM0 IRL12`）：`I2C_ERR`（Error Interrupt，FIFO 上溢/下溢错误中断）。
* `IRQ 21`（`IM0 IRL13`）：`I2C_P`（Protocol Interrupt，地址匹配、NACK、仲裁丢失与传输结束协议中断）。

### 1. I2C 控制器完整寄存器映射表（基址 `0x1E200000`）

| :--- | :--- | :--- | :--- |
| `+0x00` | `I2C_CLC` | RW | **时钟控制寄存器**：`ORMC`（位 `[23:16]`）、`RMC`（位 `[15:8]`，常设为 `1`）、`FSOE`（位 `[5]`）、`SBWE`（位 `[4]`）、`EDIS`（位 `[3]`）、`SPEN`（位 `[2]`）、`DISS`（位 `[1]`）、`DISR`（位 `[0]`）。 |
| `+0x08` | `I2C_ID` | RO | **模块标识寄存器**：`ID`（位 `[15:8]`）、`REV`（位 `[7:0]`）。 |
| `+0x10` | `I2C_RUN_CTRL` | RW | **运行状态切换寄存器**：`RUN`（位 `[0]`）：`0` = 配置状态（仅当 `RUN = 0` 时允许修改 `FDIV_CFG`、`ADDR_CFG`、`FIFO_CFG`）；`1` = 激活 I2C 总线状态机进入运行态。 |
| `+0x14` | `I2C_ENDD_CTRL` | WO | **传输结束与重复起始控制寄存器**：<br>• `SETRSC`（位 `[1]`，`0x02`）：写 `1` 在当前传输后发出 Repeated START（重复起始条件）而非 STOP。<br>• `SETEND`（位 `[0]`，`0x01`）：写 `1` 结束当前消息并在总线上发出 STOP 停止条件。 |

| `+0x1C` | `I2C_FDIV_HIGH_CFG` | RW | **高速模式（High-Speed 3.4 MHz）分频寄存器**：`INC`（位 `[23:16]`）与 `DEC`（位 `[10:0]`）。 |

| `+0x2C` | `I2C_MRPS_CTRL` | RW | **最大接收包字节数控制寄存器（Maximum Received Packet Size）**：位 `[13:0]` 指定主机读事务期望接收的字节数。 |
| `+0x30` | `I2C_RPS_STAT` | RO | **已接收包字节数状态寄存器**：反映当前事务实际已接收的字节计数。 |
| `+0x34` | `I2C_TPS_CTRL` | WO | **发送包字节数控制寄存器（Transmit Packet Size）**：位 `[13:0]` 写入本次待发送的总字节数，写入后触发发送状态机。 |
| `+0x38` | `I2C_FFS_STAT` | RO | **FIFO 填充字数状态寄存器**：`FFS`（位 `[3:0]`，取值 `0`–`8`）指示 8 字深硬件 FIFO 当前占用的 32 位字数。 |
| `+0x60`–`+0x68` | `I2C_ERR_IRQSM` / `SS` / `SC` | RW / RO / WO | **错误中断屏蔽、状态与清除寄存器**：位 `[3]` `TXFL_OFL`（发送上溢）、位 `[2]` `TXFL_UFL`（发送下溢）、位 `[1]` `RXFL_OFL`（接收上溢）、位 `[0]` `RXFL_UFL`（接收下溢）。 |

## 2.3 同步串行 SPI 控制器（`SSC0` `0x1E100D00`）

`SSC0`（Synchronous Serial Controller 0，物理基址 `0x1E100D00`）提供全双工同步串行（SPI）接口，除用于连接外部 SPI 外设（如语音 SLIC、外部传感器或扩展芯片）外，内部还集成一组 8 位通用输出片选锁存器（`GPOCON` / `GPOSTAT` / `WHBGPOSTAT`）用于驱动最多 8 路硬件片选信号 `CS0`–`CS7`。

### 1. `SSC0` 寄存器映射表（基址 `0x1E100D00`）

| 偏移量 | 寄存器名称 | 读写属性 | 关键位域与硬件功能说明 |
| :--- | :--- | :--- | :--- |
| `+0x00` | `SSC_CLC` | RW | **时钟控制寄存器**：`RMC`（位 `[15:8]`，分频系数）、`DISS`（位 `[1]`）、`DISR`（位 `[0]`）。 |
| `+0x04` | `SSC_PISEL` | RW | **端口输入选择寄存器**：选择主模式 `MRST`（MISO）或从模式 `MTSR`/`SCLK` 输入复用源。 |
