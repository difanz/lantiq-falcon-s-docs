# 2.2 系统控制与状态寄存器

Lantiq Falcon（PEB/PEF 98035）通过五个全局控制与状态寄存器模块管理芯片标识、熔丝校准参数、片上内存重映射、三域时钟门控、模块复位、NMI 路由、以太网接口复用及 GPE 电源状态：

1. **`STATUS`（物理基址 `0x1E802000`，KSEG1 `0xBE802000`）**：芯片标识、晶圆坐标、eFuse 模拟校准值与硅片步进配置。
2. **`SBS0CTRL`（物理基址 `0x1F080000`，KSEG1 `0xBF080000`）**：SBS0 片上内存保护窗口与内置 GPHY 固件地址重映射。
3. **`SYS1`（物理基址 `0x1EF00000`，KSEG1 `0xBEF00000`）**：主系统与外设域时钟、激活、复位、CPU/EBU 分频、基础设施模拟前端与 NMI 控制。
4. **`SYS_ETH`（物理基址 `0x1DB00000`，KSEG1 `0xBDB00000`）**：以太网域时钟、复位、外部 PHY 时钟、GMAC 端口复用（`GMUXC`）与数据速率（`DRC`/`DRS`）控制。
5. **`SYS_GPE`（物理基址 `0x1D700000`，KSEG1 `0xBD700000`）**：GPON 封包处理引擎（GPE）域时钟、复位与电源门控睡眠状态机控制。

## 2.2 `SBS0CTRL` 模块寄存器组（`0x1F080000`）

`SBS0CTRL` 管理 `SBS0RAM`（`0x1F200000`）的访问边界保护以及内置双路 GPHY（`GPHY0` / `GPHY1`）的固件镜像地址重映射：

| 偏移量 | 寄存器名称 | 位域定义与硬件行为 |
| :--- | :--- | :--- |
| `+0x00` | `BAR0` | **基址保护寄存器 0**：`LOCK`（位 `[31]`，`1` = 锁定寄存器禁止修改）、`WPV0`（位 `[30]`，`1` = 触发写保护异常）、`BA0V`（位 `[21:12]`，配置区域边界地址高位）、`BA0F`（位 `[11:0]`，固定为 `0`）。 |
| `+0x08` | `BAR1` | **基址保护寄存器 1**：`LOCK`（位 `[31]`）、`WPV1`（位 `[30]`）、`BA1V`（位 `[21:12]`，复位值 `0x3FF`）、`BA1F`（位 `[11:0]`，固定为 `0xFFF`）。 |
| `+0x10` | `GPHY0IMG` | **GPHY0 固件镜像重映射地址寄存器**：`ADDRV`（位 `[21:14]`，掩码 `0x003FC000`）指定 `SBS0` 空间内按 16 KiB 对齐的固件起始偏移；`ADDRI`（位 `[13:0]`）恒为 `0`。当固件拷入 `0x1F204000` 时，写入 `0x00204000`。 |
| `+0x18` | `GPHY1IMG` | **GPHY1 固件镜像重映射地址寄存器**：位域与 `GPHY0IMG` 相同，用于指定 `GPHY1` 的 16 KiB 对齐固件起始偏移。 |
| `+0x20` | `MCTRL` | **内存控制寄存器**：`DSC`（位 `[0]`）控制片上 RAM 休眠状态（`0` = 正常工作模式，`1` = 进入低功耗保持休眠模式）。 |

## 2.3 三大系统控制块公共寄存器头（`SYS1` / `SYS_ETH` / `SYS_GPE`）

`SYS1`（`0x1EF00000`）、`SYS_ETH`（`0x1DB00000`）与 `SYS_GPE`（`0x1D700000`）在前 `0x30` 字节采用完全一致的「写 1 置位 / 写 1 清零」无锁硬件控制接口：

| 偏移量 | 寄存器名 | 访问类型 | 硬件行为说明 |
| :--- | :--- | :--- | :--- |
| `+0x00` | `CLKS` | RO | **时钟门控状态寄存器（Clock Status）**：反映各子模块当前时钟门控状态（`0` = 时钟关闭，`1` = 时钟开启）。 |
| `+0x04` | `CLKEN` | WO (W1S) | **时钟使能寄存器（Clock Enable）**：向对应位置 `1` 开启该模块时钟（置位 `CLKS` 对应位），写 `0` 无影响。 |
| `+0x08` | `CLKCLR` | WO (W1C) | **时钟关闭寄存器（Clock Clear）**：向对应位置 `1` 关闭该模块时钟（清零 `CLKS` 对应位），写 `0` 无影响。 |
| `+0x20` | `ACTS` | RO | **模块激活状态寄存器（Activation Status）**：反映各子模块当前复位释放与激活状态（`0` = 处于复位/未激活态，`1` = 已激活运行）。 |
| `+0x24` | `ACT` | WO (W1S) | **模块激活寄存器（Activate）**：向对应位置 `1` 释放该模块硬件复位并激活模块（置位 `ACTS` 对应位）。 |
| `+0x28` | `DEACT` | WO (W1C) | **模块去激活寄存器（Deactivate）**：向对应位置 `1` 将该模块置入硬件复位保持状态（清零 `ACTS` 对应位）。 |
| `+0x2C` | `RBT` | WO (Pulse) | **模块软复位触发寄存器（Reboot）**：向对应位置 `1` 产生单次硬件复位脉冲，复位完成后硬件自动将该位清零。 |

## 2.4 `SYS1` 专有寄存器组（`0x1EF00000`）

除 `+0x00`–`+0x2C` 的时钟与复位控制头外，`SYS1` 还提供 CPU 分频、启动模式、模拟基础设施及 NMI 控制寄存器：

| 偏移量 | 寄存器名称 | 关键位域与硬件功能说明 |
| :--- | :--- | :--- |
| `+0x40` | `CPU0CC` | **CPU0 时钟控制寄存器**：`CPUDIV`（位 `[0]`）：`0` = 标称全速频率（400 MHz），`1` = 二分频降速运行（200 MHz）。 |
| `+0x60` | `CPU0RS` | **CPU0 复位源状态寄存器**：`SWRRO`（位 `[2]`，软复位请求曾触发标志，写 `0` 清零）；`HWRS`（位 `[1:0]`，硬件复位源：`00` = 上电复位 POR，`01` = 外部 `RST` 引脚复位，`10` = 看门狗 `WDT` 超时复位）。 |
| `+0x80` | `CPU0WCFG` | **CPU0 休眠唤醒配置寄存器**：`WUP`（位 `[31:0]`）掩码选择允许将 CPU0 从 `WAIT` 低功耗指令状态唤醒的中断源。 |
| `+0xA0` | `BMC` | **启动模式控制寄存器（Boot Mode Control）**：`BMSW`（位 `[31]`，`0` = 使用外部引脚采样的硬件启动模式，`1` = 使用本寄存器位 `[6:0]` `BM` 的软件启动模式值）。 |
| `+0xB0` | `SCFG` | **休眠配置寄存器（Sleep Config）**：`VPE1SL`（位 `[10]`）、`VPE0SL`（位 `[9]`）、`CPU0CG`（位 `[8]`，CPU0 `WAIT` 态自动门控时钟）、`SBUSSL`（位 `[2]`）、`DDRSL`（位 `[1]`）、`EBUSL`（位 `[0]`）。 |
| `+0xB4` | `PDCFG` | **SYS1 域电源门控配置寄存器**：控制 `SHA1`（位 `[30]`）、`AES`（位 `[29]`）、`PCM`（位 `[28]`）、`FSCT`（位 `[27]`）、`GPTC`（位 `[26]`）、`MPS`（位 `[25]`）、`DFEV0`（位 `[24]`）等模块的自动电源关断。 |
| `+0xB8` | `CLKOC` | **时钟输出控制寄存器**：`ETHREF`（位 `[1]`，`1` = 开启以太网参考时钟输出）、`OEN`（位 `[0]`，`1` = 开启主时钟输出缓冲驱动）。 |
| `+0xBC` | `INFRAC` | **基础设施控制寄存器（Infrastructure Control）**：<br>• `GP`（位 `[28:24]`）：通用基础设施控制位，其中位 `[24]` 为配置模式使能（`configmode_on`），位 `[25]` 为 GPE 主时钟使能，位 `[27:26]` 为 GPE 主时钟频率选择（`00`=769.2 MHz，`01`=625 MHz，`10`=555.6 MHz，`11`=500 MHz）。<br>• `CMOS2CML_GPON`（位 `[15:12]`）：GPON SerDes CMOS-to-CML 偏置控制。<br>• `CMOS2CML_ETH`（位 `[11:8]`）：以太网 SGMII CMOS-to-CML 偏置控制。<br>• `DGASPEN`（位 `[6]`）/ `DGASPHYS`（位 `[5:4]`）：Dying Gasp 掉电告警比较器使能与迟滞阈值。<br>• `LIN1V5EN`（位 `[3]`）/ `LIN1V5C`（位 `[2:0]`）：片内 1.5 V 线性稳压器（LDO）使能与输出电压微调（`0`=1.39V 至 `7`=1.62V，默认 `3`=1.50V）。 |
| `+0xC0` | `HRSTOUTC` | **硬件复位输出引脚控制寄存器**：`VALUE`（位 `[0]`）控制片外复位输出引脚 `HRST_OUT_N` 的电平状态。 |
| `+0xC4` | `EBUCC` | **EBU 时钟控制寄存器**：`EBUDIV`（位 `[0]`）：`0` = EBU 总线运行于 50 MHz，`1` = EBU 总线运行于 100 MHz。 |
| `+0xD0` | `NMIS` | **NMI 状态寄存器**：位 `[2]` `DGASP`（掉电告警 NMI）、位 `[1]` `PLL`（锁相环失锁 NMI）、位 `[0]` `PIN`（外部 NMI 引脚触发）。 |
| `+0xD4` / `+0xD8` | `NMISET` / `NMICLR` | **NMI 置位与清除寄存器**：支持软件触发或清除 `DGASP`、`PLL`、`PIN` 三路 NMI 请求。 |
| `+0xDC` | `NMITCFG` | **NMI 外部引脚触发极性配置**：`PIN`（位 `[0]`，`0` = 上升沿触发，`1` = 下降沿触发）。 |
| `+0xE0` | `NMIVPE1C` | **NMI 路由至 VPE1 控制寄存器**：位 `[2:0]` 分别控制 `DGASP`、`PLL`、`PIN` 触发时是否送往 VPE1 而非 VPE0。 |
| `+0xF0`–`+0xF8` | `IRNCR` / `IRNICR` / `IRNEN` | **SYS1 中断状态、捕获与使能寄存器**：位 `[2:0]` 对应 `DGASP`、`PLL`、`PIN` 事件中断。 |

## 2.5 `SYS_ETH` 与 `SYS_GPE` 专有寄存器组

### 1. `SYS_ETH` 专有控制寄存器（`0x1DB00000`）

| 偏移量 | 寄存器名称 | 关键位域与硬件功能说明 |
| :--- | :--- | :--- |
| `+0xB0` | `EXTPHYC` | **外部 PHY 时钟控制寄存器**：`CLKOEN`（位 `[3]`，`1` = 开启时钟输出引脚驱动）；`CLKSEL`（位 `[2:0]`，`001` = 25 MHz，`010` = 50 MHz，`101` = 125 MHz）。 |
| `+0xB4` | `PDCFG` | **以太网域电源门控配置**：控制 `GPHY1MII2`、`GPHY0MII2`、`PADCTRL2`、`PADCTRL0`、`P2`、`P0`、`xMII`、`SGMII`、`GPHY1`、`GPHY0`、`MDIO`、`GMAC3–0` 的空闲电源关断。 |
| `+0xB8` | `DRC` | **数据速率控制寄存器（Data Rate Control）**：每 3 位配置一个端口速率（`000`=10M，`001`=100M，`010`=1000M，`100`=200M，`101`=2500M）：`SGMII`（位 `[26:24]`）、`xMII1`（位 `[22:20]`）、`xMII0`（位 `[18:16]`）、`GPHY1_MII2`（位 `[14:12]`）、`GPHY1_GMII`（位 `[10:8]`）、`GPHY0_MII2`（位 `[6:4]`）、`GPHY0_GMII`（位 `[2:0]`）。 |
| `+0xBC` | `GMUXC` | **GMAC 端口物理层复用寄存器（GMAC Multiplexer Control）**：每 3 位选择对应 `GMACn` 连接的物理接口：`GMAC3`（位 `[14:12]`）、`GMAC2`（位 `[10:8]`）、`GMAC1`（位 `[6:4]`）、`GMAC0`（位 `[2:0]`）。编码值：`0`=`GPHY0_GMII`，`1`=`GPHY0_MII2`，`2`=`GPHY1_GMII`，`3`=`GPHY1_MII2`，`4`=`SGMII`，`5`=`xMII0`，`6`=`xMII1`。 |
| `+0xC0` | `DRS` | **GMAC 实际数据速率状态寄存器（只读）**：反映 `GMAC3`（位 `[14:12]`）至 `GMAC0`（位 `[2:0]`）经复用器选通后的当前工作速率。 |
| `+0xC4` | `SGMIIC` | **SGMII 参考时钟源配置寄存器**：`CLKSEL`（位 `[1:0]`）：`00` = 125 MHz 内部 PLL 参考时钟，`01` = 125 MHz 外部差分引脚时钟，`10` = 250 MHz 内部 PLL，`11` = 250 MHz 外部差分引脚。 |

### 2. `SYS_GPE` 专有控制寄存器（`0x1D700000`）

| 偏移量 | 寄存器名称 | 关键位域与硬件功能说明 |
| :--- | :--- | :--- |
| `+0xB4` | `PDCFG` | **GPE 子模块自动电源门控使能寄存器**：位域分布与 `SYS_GPE_CLKS` 一致（涵盖 `COP7–0`、`PE5–0`、`ARB`、`FSQM`、`TMU`、`MRG`、`DISP`、`IQM`、`CPUE/I`、`GPONE/I`、`LAN3–0`）。 |
| `+0xB8` | `SSCFG` | **GPE 睡眠状态机周期配置寄存器**：`SWTIME`（位 `[6:0]`，默认 `0x05`）定义电源开关切换等待周期数。 |
| `+0xBC` | `SST` | **GPE 睡眠状态机手动触发寄存器**：`TRIG`（位 `[0]`，写 `1` 触发电源开关状态转换）。 |
| `+0xC0`–`+0xC8` | `SDS` / `SDSET` / `SDCLR` | **GPE 子域断电状态、置位与清除寄存器**：位域分别控制 `COP7–0`（位 `[31:24]`）、`PE5–0`（位 `[21:16]`）等模块的电源域关断（Shut Down）。 |
| `+0xF0`–`+0xF8` | `IRNCSCR` / `IRNCSICR` / `IRNCSEN` | **GPE 时钟唤醒中断状态、捕获与使能寄存器**：监控各 GPE 子模块的时钟恢复请求事件。 |
