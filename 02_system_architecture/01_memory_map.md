# 2.1 物理地址映射与总线拓扑

Lantiq Falcon（PEB/PEF 98035）的全部片上内存、外部存储窗口与外设寄存器均统一编址在物理地址空间低 512 MiB（`0x00000000`–`0x1FFFFFFF`）内。MIPS 34Kc 处理器通过无 TLB 直接映射虚拟段访问该物理空间：

* **`KSEG0`（`0x80000000`–`0x9FFFFFFF`）**：经过 L1 指令/数据缓存（Cacheable）映射到物理地址 `0x00000000`–`0x1FFFFFFF`，用于访问 DDR2 SDRAM（`0x80000000`–`0x83FFFFFF`）及需要缓存加速的 `SBS0RAM` 区域。
* **`KSEG1`（`0xA0000000`–`0xBFFFFFFF`）**：绕过缓存（Uncached）直接映射到物理地址 `0x00000000`–`0x1FFFFFFF`，用于访问全部 MMIO 外设寄存器（`0xBD000000`–`0xBF8803FF`）、复位启动向量（`0xBF200000` / `0xBFC00000`）以及 EBU 闪存映射窗口（`0xB0000000`）。
