# 2.4 中断控制器与向量表

Falcon 的 ICU 包含 IM0–IM4 五组、每组 32 条外设输入，汇总到 MIPS CP0 的 IP2–IP6。ICU 物理基址为 `0x1F880200`，KSEG1 地址为 `0xBF880200`。

硬件中断由 ICU 组号 `k` 和组内位号 `b` 标识。将 CP0 的 8 个输入编号保留在前时，可用 `8 + 32 * k + b` 表示 ICU 输入的线性编号。操作系统还可为这些输入分配独立的虚拟 IRQ；该虚拟编号不属于 SoC 固定接线。

## 4.1 CP0 与 ICU 级联

```mermaid
flowchart LR
    DEV["外设源状态与使能"] --> ICU["IM0–IM4，每组32位"]
    ICU --> CP0["CP0 IP2–IP6"]
    CP0 --> DISPATCH["读取IOSR并分派hwirq"]
```

| CP0 输入 | 输入编号 | 用途 |
|---|---|---|
| IP0、IP1 | 0、1 | 软件中断；是否用于 IPI 取决于内核配置 |
| IP2–IP6 | 2–6 | IM0–IM4 级联输入 |
| IP7 | 7 | CP0 Count/Compare 定时器中断 |

软件中断可用于处理单元间通知，具体分配由系统规定。SFP 设备服务通过共享内存交换 EEPROM 数据，其协议另见[多线程与 VPE1](../03_cpu_subsystems/02_vpe1_sfp_i2c.md)。

## 4.2 ICU 寄存器组

组 `k` 的物理基址为 `0x1F880200 + k * 0x28`，`k=0..4`，每组占 `0x28` 字节。

| 组 | 物理基址 | CP0 输入 | hwirq 范围 |
|---|---|---|---|
| IM0 | `0x1F880200` | IP2 | 8–39 |
| IM1 | `0x1F880228` | IP3 | 40–71 |
| IM2 | `0x1F880250` | IP4 | 72–103 |
| IM3 | `0x1F880278` | IP5 | 104–135 |
| IM4 | `0x1F8802A0` | IP6 | 136–167 |

| 组内偏移 | 名称 | 功能 |
|---|---|---|
| `0x00` | ISR | 状态；向目标位写 1 应答 |
| `0x08` | IER | 使能；读改写目标位以屏蔽/恢复 |
| `0x10` | IOSR | 读取已输出的挂起位，分派外设中断 |
| `0x18` | IRSR | 原始状态寄存器定义 |
| `0x20` | IMR | 模式寄存器定义 |

屏蔽并应答一个 ICU 输入时，先清除 IER 的目标位，再向 ISR 写入相同位。ICU 应答与外设内部源状态清除是两个操作；外设状态未清除时可能再次产生请求。

## 4.3 外设中断输入映射

下表列出已明确的 ICU 输入；其余输入的分配不在本表规定范围内。线性编号采用前述 `8 + 32 * k + b` 约定。

| ICU 组/位 | 中断源 | 线性编号 |
|---|---|---|
| IM0/10–13 | I2C Last Burst、Burst、Error、Protocol | 18、19、20、21 |
| IM0/14–16 | SSC TX、RX、Error | 22、23、24 |
| IM1/4–8 | GPIO0–4 | 44–48 |
| IM1/14 | TOD | 54 |
| IM1/15–17 | PMA_200M、PMA_TX、PMA_RX | 55、56、57 |
| IM2/10 | IQM | 82 |
| IM2/12 | TMU | 84 |
| IM2/14 | LINK1 | 86 |
| IM2/19–20 | CONFIG_BREAK、CONFIG | 91、92 |
| IM2/29–30 | GTC_DS、GTC_US | 101、102 |
| IM3/0–2 | ASC0 TX、RX、Error | 104、105、106 |
| IM3/8–10 | ASC1 TX、RX、Error | 112、113、114 |
| IM4/18–19 | MPS 两条中断输入 | 154、155 |

中断接线与使能状态相互独立。外置光模块的信号检测等 GPIO 事件还取决于板级引脚分配，并先经过 GPIO 组内中断逻辑。GPTC 各通道的 ICU 接线尚未确认，本表不为其分配编号。

## 4.4 外设内部的中断源

多种外设有 IRNCR（捕获/应答）、IRNICR（注入控制）和 IRNEN（使能）一类寄存器，但偏移、读写属性、屏蔽与锁存关系须按具体模块核对。不能将一套通称强行套用到 I2C、GPIO、GTC 或其他全部模块。例如 GPIO 的中断模式由 IRNCFG 选择，IRNENSET/CLR 提供原子使能控制，详见[GPIO 寄存器表](../04_peripherals_and_io/01_pinctrl_and_gpio.md)。
